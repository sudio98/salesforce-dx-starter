Agentic Enterprise 소개 영상
Dreamforce 100일 뒤, 크리스마스가 찾아옵니다.
매년 Santa Company는 크리스마스를 완벽하게 준비해왔지만, 올해는 위기 상황에 놓입니다. 세상이 그 어느 때보다 빠르게 바뀌는 가운데, 전 세계의 착한 아이들(고객)이 기대하는 높은 기준을 계속 충족할 수 있을까요?

해답은 Agentic Enterprise입니다.
Apromore, Piper, Carter, Felix, Agentforce Coworker, Slackbot이 함께 등장하는 이 스토리는 Salesforce가 어떻게 크리스마스를 구해내는지 보여줍니다.

영상 속 비유
Santa: 비즈니스 리더 / Elves: 임직원 / Children: 고객
또한 영상의 연출 자체도 Headless를 비유합니다. 엘프들의 뒷모습 장면은 사람이 실제로 일하는 UI/현장을, 화면 전체를 채우는 데모 장면은 에이전트가 작업을 처리하는 실행 레이어를 의미합니다. 즉, UI와 실행 레이어가 분리되어 있으면서도 유기적으로 연결되는 Headless 구조를 직관적으로 전달합니다.

직원과 AI 에이전트가 하나의 팀으로 협업할 때, 복잡한 업무도 더 빠르고 정확하게 실행됩니다.

Headless Interface
Headless Interface는 CRM의 데이터, 로직, 거버넌스를 특정 UI에 종속시키지 않고, 어떤 인터페이스에서도 동일한 Agent, 데이터, 로직을 재사용할 수 있게 만드는 구조입니다.
자세한 자료는 여기에서 확인하세요.
라이선스/과금 핵심 정리
  • 기본 조합은 AUL(Agentforce User License) + Flex Credits입니다.
  • Agent가 참조할 업무 컨텍스트를 쓰려면 해당 Cloud 라이선스(Sales/Service/Revenue 등)가 뒷받침되어야 합니다.
  • 각 user license에는 월별 Headless Platform Interaction 기본 용량이 포함되며, 초과 시 Flex Credits 소모 또는 Add-On/A4X/A1E 업그레이드가 필요합니다.
  • 3rd-party agent(예: Claude+MCP, Agent Identity 등록) 호출은 Headless Interaction이 아닌 Agentforce/Data 360 사용량 기준으로 과금됩니다.
주의
Headless Platform Interaction 과금(외부 에이전트의 데이터/API 조회)과 AUL + Flex Credits 과금(Agentforce 추론·액션 실행)은 서로 다른 과금 체계입니다.

각 인터페이스 버튼을 눌러 실제 동작 방식을 확인해보세요.

1. FIN은 어디에 포함되나요?
Fin은 Headless 360 레이어 안의 컴포넌트라기보다 별도 브랜드 제품으로 보는 게 맞습니다.
Salesforce 미사용 SMB 고객 대상의 독립 패키지로 유지되며, 내부 포지셔닝도 Fin ≠ Casey(Agentforce Help Agent)로 명확히 구분됩니다.
즉 Casey는 Salesforce 고객용 네이티브 Agent이고, Fin은 병렬로 존재하는 독립 상품입니다.
2. Momentum은 어디에 포함되나요?
Momentum은 화면에 노출되는 Named Agent 페르소나라기보다, 통화·이메일·미팅 데이터를 구조화해 Agent에게 공급하는 입력/센싱(컨텍스트) 레이어입니다.
실무 표현으로는 "Agentforce is the brain, Momentum is the ears"에 가깝고, Hunter·Archer 같은 Sales Agent가 참고할 근거 데이터를 채우는 백엔드 인텔리전스 역할입니다.
현재는 이 기능이 Agentforce for Sales(A4S) 네이티브 기능으로 통합되는 과도기이며, 기준 시점(9/20) 이후에는 A4S 내 기능으로 정리되는 방향입니다.
